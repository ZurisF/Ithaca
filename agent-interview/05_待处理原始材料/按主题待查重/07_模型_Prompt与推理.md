# 模型、Prompt 与推理：语义查重审计

## 审计口径

- 对照正式题库：[`agent-interview/按考点/模型_Prompt与推理.md`](../../按考点/模型_Prompt与推理.md)。只有核心考点和预期答案实质相同才判“语义重复”；新增条件或考点仍保留。
- 本主题覆盖模型选型与职责、生成和推理、Prompt、模型训练范式、模型侧幻觉控制、推理引擎及推理性能。主要考查 RAG、评测、上下文管理、工具编排、安全边界或一般系统流程的题记为“不迁入”，交由相应主题审计。
- 来源之间即使题意相近，也逐题保留，不相互合并；同一来源的不同场次出现相同问法时也分别记录。仅有正式题库已有语义覆盖的题目标“语义重复”。
- “新增迁入”表示该题应独立追加至正式题库；“语义重复”列出正式题库中的匹配题；“不迁入”说明主题归属或不构成独立模型考点的原因。
