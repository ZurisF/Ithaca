# 待处理面经题目：按主题查重与迁移

本目录按 `按来源/` 中的原始来源文件聚合题目，并记录与当前正式题库的语义查重结论。来源文件保留不动，便于回溯。

## 查重范围与处理规则

- 当前正式题库仅指 [`../../按考点/`](../../按考点/) 中的 11 个主题文件；`agent-interview/README.md` 明确说明其它研究过程、旧版和主题线索目录不是导入入口。
- 每道来源题目归入一个主要主题，聚合文件保留来源文件名、场次和题干。
- 语义重复项留在本目录的审计记录中，不重复追加到正式题库；结论须指出对应的现有题目，并简述重复点。
- 有新考点或具体业务约束的题目，即使与现有题目相近，也可以作为新题迁入；保留原问法，不要把不同来源的问题合并成一条。
- 与 Agent / AI 应用题库范围无关的通用题目记录为“不迁入”。来源原文始终保留。
- 每个主题由单独 subagent 负责一个聚合审计文件和一个对应正式题库文件。subagent 不修改来源文件、其它主题文件或 README。
