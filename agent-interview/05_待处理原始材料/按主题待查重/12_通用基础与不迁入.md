# 通用基础题与不迁入题

本文件是交叉审计记录，不作为正式题库导入文件。本轮只核对 13 份按来源稿和 `agent-interview/按考点/` 的 11 个正式主题；不改写来源题，也不推测原帖中没有保留或不可见的内容。

## 判定口径

- 通用算法、编码和调试题若不考察 AI / Agent 机制，留在本审计记录，不迁入 AI / Agent 专项题库。仅考查领域相同（例如都是算法题）不算语义重复。
- 纯自我介绍、求职动机、职业方向选择和面试反问属于面试流程或个人表达，不作为专项能力题迁入。
- 如果问题虽通用，但正式 11 个主题已有语义相同的问题，则标为“已有主题承担”，不再重复收录。
- 题目明确询问 Agent 如何分解、执行任务，或询问 AI Coding 能力时，不因其示例是常见算法就误归为纯通用题；此类边界题留给相应专项主题审查。

## 结论

本主题识别到的确定通用项是链表编码、代码调试、文件重复行 / 外存处理、实时 Top-10 排行，以及若干自我介绍、求职动机、职业偏好和反问环节。这些内容不迁入 AI / Agent 专项题库。拓扑排序、线程与进程、ForkJoin、需求交付阶段等虽属通用知识，但已由现有 11 个主题承担；带有 Agent 任务执行语境的 `abcabc` 并发例题和 Agent 防抖问题则不按纯通用题处理。
