# Coding Agent 与开发工具：本轮语义查重

## 比对口径

逐条比对本轮开始前 `agent-interview/按考点/CodingAgent与开发工具.md` 中已有的 18 道题。只有核心能力与答案实质相同才判为“语义重复”；新场景、新约束或新考点保留。本批来源之间即使问法相似，也各自记录并迁入，不相互替代。来源 09 的旧稿补充题按原有标注视为归属待回看。

结论含义：**新增迁入**表示追加到正式题库；**语义重复**表示已有题已覆盖；**不迁入**表示主要归属其他主题或不是本主题问题。
