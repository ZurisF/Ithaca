# RAG、检索与知识库：语义查重与迁移

对比范围：当前正式题库 [RAG_检索与知识库.md](../../按考点/RAG_检索与知识库.md) 中已有的 36 道题。判断标准是核心能力和预期解法是否实质相同；新场景约束或新考点予以保留。来源之间相近的题目不互相去重，每道未被正式题库覆盖的来源题均独立迁入。

结论说明：**新增迁入**表示正式题库尚未覆盖，已按原来源问法追加；**语义重复**表示已有题覆盖主要考点，不重复追加；**不迁入**表示主考点属于其他主题或只是项目背景。
