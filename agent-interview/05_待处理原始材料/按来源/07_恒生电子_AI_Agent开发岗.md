# 恒生电子 AI Agent 开发岗面经

来源：https://www.nowcoder.com/discuss/940029270502424576

**面经 01–04 中可见的 Agent / AI 应用题**

1. MCP 是什么，怎样使用？
2. 用 AI 开发时是否有自己的工作流，如何组合裸 Agent、Skill、Spec 和 Workflow？
3. Agent 项目是自己主导还是加入既有项目，框架为何这样选？
4. 对哪些开源 Agent 框架做过了解？为什么不直接基于现成 Agent 开发？
5. MCP 一次完整交互包含什么步骤，客户端负责哪些环节？
6. 客户端同时请求多类 MCP 能力时，服务端怎样安排与协调响应？
7. 常见上下文管理方式有哪些？上下文清理后怎样保留用户偏好？
8. 陪伴型 Agent 如何判断何时召回长期记忆？
9. RAG、传统检索生成和模型微调分别适用于哪些问题？
10. 知识过期或相互冲突时，问答 Agent 应怎样选择策略？
11. 用户明确询问旧知识时，怎样避免查询改写把问题带到新知识？
12. 受控编辑如何避免大模型不安全地直接修改内容？
13. 如何用指标证明受控编辑优于模型直接写入？
14. 为什么采用 LangGraph 状态图而不自研，Checkpoint 与业务状态冲突时如何处理？
15. 怎样提高大模型输出 JSON 等结构化数据的稳定性？
