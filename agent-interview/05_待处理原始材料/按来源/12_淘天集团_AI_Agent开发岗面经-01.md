## 面经 01（AI 应用开发工程师）

1. 请自我介绍并介绍简历项目。
2. Agent 主要实现什么功能，执行链路是什么？
3. Agent 读取代码库时从哪里、怎样读取？修改代码的流程是什么？
4. 代码修改后怎样管理和提交到 Git？
5. 面对一个小需求，Agent 如何分析、拆解任务并逐步实现？
6. 以三个线程交替输出 abcabc 为例，Agent 会怎样一步步完成？
7. 需求交给模型后，模型返回什么？
8. 结合上下文和现有代码库新增功能，与从零实现有什么不同？
9. 现有接口已有策略 A、B，需要添加 C 时，模型先返回什么、后续如何调用？
10. Agent 目前处理过最复杂的问题是什么？
11. “获取知识”指联网查询还是读取已有知识库？本地代码库如何组织和检索？
12. 了解哪些 RAG 分片和索引方式？召回片段不完整时怎样处理？除文件分片外还可怎样存储？
13. 最近还学习或探索了哪些 AI 内容？怎样理解 Harness？
14. Harness 相比 Agent 调 MCP 或使用 ReAct 增加了什么能力？哪些要素让它更稳定、安全？

## 面经 02（AI Agent 开发岗）

1. 请介绍项目及其中最难解决的问题。

4. 如何理解 Skill？

7. 对 LangChain 和 LangGraph 有什么了解？

## 面经 03（AI Agent 开发岗）

1. 多阶段 RAG 中如何融合 BM25 与向量召回，混合检索在哪个环节提升效果？
2. PDF 扫描件、OCR 和表格结构化处理遇到过什么问题，识别准确率大致如何？
3. State 与 Checkpoint 如何实现，多个 Agent 并发执行时怎样避免状态竞争并管理全局状态？
4. 将 Choice 接口封装成 MCP 工具时，标准接口怎样设计，有哪些兼容问题？请举例说明输入和输出参数。
5. 没有 MCP 时，大模型调用工具的流程是什么？MCP 有哪些缺点或挑战？
6. MCP 返回是否支持流式？多 Agent 项目采用主从结构吗？
7. 单次会话大约消耗多少 Token，是否遇到上下文超限？使用哪个模型和版本？
8. 子任务失败（例如抓取结果为空）时，工作流怎样重试或降级？
9. FastAPI + SSE 与 LangGraph 配合时，怎样捕获节点执行结果并实时推送前端？
10. 为什么选择 LangGraph，而不是更简单的 LangChain？

## 面经 04（AI Agent 开发工程师）

1. 常规分类为什么采用推理式建模，而不是传统分类器？
2. 多业务标准不同，单个模型如何承载多任务并避免相互冲突？
3. 单正例、多负例的 DPO 能否学会负样本间的排序？
4. DPO 后是否可以继续做 GRPO？分类任务中 DPO 与 GRPO 的效果差异是什么？
5. 单轮 LLM 打分是否属于 Agent，与多轮工具调用 Agent 有何区别？
6. Skill、Memory、RAG 分别解决什么问题？
7. Agent Memory 如何迭代更新，矛盾的新旧经验如何取舍？
8. 仅使用最终结果作奖励是否足够，多步工具轨迹如何分配信用？
9. 判别式任务为何逐步转向生成式对话和自主 Agent？
10. 在线 on-policy 蒸馏与强化学习有何差异，哪种更可能超过教师模型能力？
