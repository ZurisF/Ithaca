# 快手电商大模型应用开发一面

来源：https://www.nowcoder.com/feed/main/detail/acc9c99b46e7489386bab12b47b56c11

以下按原帖公开可见的面试流程转述；保留业务调研、方案评估和 AI Coding 环节中的独立追问。

## 项目与业务调研

1. 请介绍实习和项目背景。
2. 怎样区分真实用户访问与 API 采集流量？
3. 如何判断流量来自哪个渠道？
4. 需求从哪里来，前期怎样调研？
5. 调研过哪些开源或同类方案？
6. 如何借助引用链接反查信息来源？
7. 来源链接怎样筛选，是否做聚类？
8. 最终为何选定这些投放平台，候选来源和平台规模多大？
9. 平台筛选使用了多长时间、多少数据？采集查询问题如何构造？

## 内容生产与效果评估

1. 怎样让生产内容更容易被 AI 引用？
2. 投放后多久能看到效果，怎样验证？
3. 是否复用爆款内容的生产流程？
4. 黑盒评估下怎样提升内容得分？
5. 调研结论和方案取舍是什么？
6. 用哪些量化指标，目标值怎样确定？
7. 产品当前更偏向流量监控还是内容优化？
8. 目前实习进展和后续优化方向是什么？

## 技术实现与 AI Coding

1. Go 技术栈中具体负责了什么？
2. 浏览器导航助手的需求是什么，半小时内怎样选定最小可演示功能？
3. 如何用 AI Coding 完成浏览器导航助手？
4. 如何拆解页面读取与保存？首次演示如何完成手动保存和页面控制？
5. 自动保存新页面是否生效，最终实现了哪些能力、还存在哪些偏差？
6. 如何向 Coding Agent 提示需求，生成结果不符合预期时怎样修正？
7. 更倾向全栈还是服务端方向？
8. 反问环节会了解团队业务和入职后的主要挑战。
