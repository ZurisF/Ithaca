## 面经 01

1. 请自我介绍，并说明项目中的模型调优和 RAG 工作。

3. 如何维护实时商品销量 Top-10 排行？
4. 用 AI Coding 设计一个会员价、满减等策略可动态更新的商品计价系统。
5. 平时如何使用 AI Coding，遇到过哪些问题？

## 面经 02

1. RAG 系统有哪些核心功能，整体链路怎样设计？
2. 知识库如何按用户、团队和组织实施权限控制？
3. 业务文档有哪些类型，系统面向内部还是外部用户？
4. 文档上传后如何自动触发切分和向量化？
5. 不依赖 Dify 时，LangChain 或 Spring AI 中有哪些文档切分策略？
6. Markdown 的多级标题怎样与正文合并切分，其他格式如何处理？
7. RAG 的 Top-K 如何选择，为什么取 6 或 8？
8. 增大 Top-K 是否会带来更多干扰或幻觉，如何权衡？
9. 召回效果不佳可能有哪些原因？
